# Changelog · TMMD

## v1.8(未发布)· 2026-10-25

### 整窗一整块玻璃(用户定调:对标 pebrel 的"一整块玻璃",不走规范式分层)
- **单一浓度**:四路 `--glass-base/chrome/reader/pop` 收成 `--glass`;氛围档 weak/medium/strong = 20/45/70(medium 即 pebrel 配置里的 `opacity=0.45`)。老存档按 `1-(1-base)(1-reader)` 折算成单一浓度,视觉不跳。
- **只画一层**:`html` / `.layout` / 铬层 / 正文区不再各自叠浓度(旧模型 base 被叠 2–3 次,总浓度不受控);`body` 成为唯一浓度层。
- **DWM 份额拆分**:`glassSplit(conc)` 把总浓度拆成 DWM 45% 份额 + 页面其余(两边相乘 = 总浓度),`applyGlassMaterial` 的 alpha 由拆分取值。
- **内容板不再是补丁**:31 处 `background: var(--bg2|--bg3|--code-bg|--bg)` 换成 `--surface-plate`(浓度 +22)/`--surface-plate-strong`(+40);代码块不再强制不透明。
- 修:`applyAtmos` 还在往存档写已废的 `base/chrome/reader/pop`(全是 `undefined`)→ 氛围档按钮失效;`.setpage-search` 在设置页里又垫了一层窗口级浓度。
- 实测(副屏抓真实合成像素):Mica 确认真机生效(`backdrop 1 → 2`);系统 Win11 backdrop(2/3)**不透明**,透不出壁纸 → "看得见的整块玻璃"只能走 legacy accent 通道。最坏情况对比度已量化(45% 浓度下亮壁纸处约 2.1:1,70% 约 4.5:1),默认浓度待用户定。

### 编辑可靠性(用户拍板:必须有编辑,不能让人去开记事本)
- **修掉一个假承诺**:外部变更监听此前**从未生效**(前端两处路径比较写错:`getTab(S.cur)` 传对象、`S.cur === p` 比字符串);现在外部改盘会真自动重载,编辑中只提示、不动草稿。路径比较统一走 `normPath()`(反斜杠/大小写无关)。
- **不再静默丢内容**:新增关窗守卫(后端 `CloseRequested` 拦下并发 `close-requested` → 前端三选弹窗 → `allow_close` 放行);关标签 / 切库 / 从磁盘刷新前同样走三选(保存 / 不保存 / 取消),替代原来只有"放弃"的 `window.confirm`。
- **原子写**:同目录临时文件 → sync → rename;中途失败原文件不动,不留半截正文。
- **换行与 BOM 不再被改掉**:textarea 会把 CRLF 归一成 LF,保存时按原文件风格还原(实测 CRLF 保留)。
- **写前冲突检测**:后端记住"读出来时"的指纹,磁盘被外部改过则返回 `CONFLICT|<路径>`;前端弹「覆盖 / 取消」,**取消时磁盘不动、草稿不丢**。
- **Ctrl+S** 保存(此前根本没有保存快捷键);保存失败不再清脏标记、不退出编辑态。
- **扩展名口径统一**:树 / 打开 / 保存 / 写回 / 对话框 / 拖放共用一份清单(`md markdown mdx html htm`,外加显式打开 `.txt`),消除"树里有、点开报错"。
- 验证:CDP 端到端 21 项全过(CRLF 保留、原子写无残留、冲突覆盖与取消、watcher 真生效、关窗守卫拦住且先存后关、`.txt` 可开可存、Ctrl+S 真按键存盘)。

## v1.7.0 — 2026-10-24 · 按竞品差距分析全面改版

依据:`docs/2026-10-24-竞品与差距分析.md`(22 款竞品 × 22 项能力矩阵 + 57 项自审 + 24 条视觉检查表)。
原则:**功能只补硬缺口,预算全投"最好看"**。

### 外观与排版(P0)
- **层级重建**:抄 WinUI elevation 语义(Card 8 / Flyout 32),统一 1px 描边,圆角收敛到 4/6/8/12/16 五档
- **排版换血**:正文默认改无衬线(可在设置切回等宽);新增**行宽**(26–52em,默认 34em ≈ 34 全角字)与**行高**(1.4–2.0,默认 1.7)滑条;`.reader-inner` 不再写死 880px
- **代码块**:底板强制不透明;新增复制按钮;新增行号列(可关)
- **图片/视频**:1px 描边 + 不透明底板,避免落在玻璃上糊边
- **空态**:强调色标题改压在不透明渣底卡片上(不再直接压模糊底)
- **动效体系**:统一 120/160/220ms + `cubic-bezier(.2,0,0,1)`;文档切换淡入;玻璃开关"结霜"过渡;尊重 `prefers-reduced-motion`
- **设置页卡片化**:7 个分区卡片 + 图标 + 分区导航

### 透明与材质(P1)
- **材质三选**:直透 / Acrylic 磨砂 / **Mica 壁纸色**(`DWMWA_SYSTEMBACKDROP_TYPE`,失败自动回落 Acrylic)
- **系统回落**:检测 Windows"透明效果"开关与高对比模式,命中则强制实色(`system_effects_state`)
- **可读性下限**:文字整体透明度下限 70%;设置页新增「可读性保底」说明(代码块/图片/卡片始终不透明);玻璃面板新增"系统状态"回显
- 保留三档氛围预设 × 四路不透明度 + 整窗底色取色

### 阅读能力
- **文内查找**:Ctrl+F 浮条、命中高亮、当前项强调、`n/m` 计数、Enter/Shift+Enter、F3、Esc
- **库级全文搜索**:侧栏新增搜索视图,跨所有已注册库做子串检索(`search_library`),命中列表可点击直达
- **脚注**:零依赖前置处理(定义行 + 续行 + 围栏代码保护),渲染为角标 + 文末脚注区
- **专注模式**(Ctrl+Shift+F):鼠标所在段落以外的内容淡出
- **无干扰模式**(F11):隐藏顶栏与侧栏,只留正文
- **外部文件变更监听**:`watch_file` 监视当前文档所在目录,`fs-changed` 事件触发自动重载(编辑中只提示不覆盖)
  - ⚠️ **更正(2026-10-25)**:本条陈述的是**设计意图**,当时前端接线写错(`getTab(S.cur)` 传对象、`S.cur === p` 比字符串),**实际从未监听**。已于 2026-10-25 修复并端到端验证(见下方 v1.8 段)。
- **续读/大纲/导读地图**:沿用

### 导出与分发
- **导出 HTML**:在文档同级写 `<name>.export.html`(内联 CSS、相对图片路径、去掉行号与搜索高亮)
- **打印 / 存 PDF**:导出后用默认浏览器打开打印
- **窗口几何**:记忆上次尺寸/位置(单一 `window.json`,逻辑像素),启动时按**当前**显示器工作区校验,越界或首次启动则取工作区 88% 居中;最小尺寸降到 520×360;窄窗自动折起侧栏的阈值 780→640(旧值让小屏每次开机都折栏)
- **界面语言**:中文 / English / 日本語(静态界面 + 新增提示;后端错误串仍为中文)
