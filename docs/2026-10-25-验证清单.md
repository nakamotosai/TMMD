## 1. 起一个"看不见"的测试实例(唯一正确姿势)

```powershell
# 一次只发一条命令;下面这条 ~5 秒返回
$env:TMMD_TEST_NOACTIVATE='1'          # 用 SW_SHOWNOACTIVATE 显示 + WS_EX_TOOLWINDOW(不进任务栏)
powershell -File <skill>\windows-hidden-desktop-verify\launch-on-secondary.ps1 `
  -Exe F:\projects\tmmd\src-tauri\target\debug\tmmd.exe -Port 9225
```

验收输出必须满足:

- `FIRST visible real window: 3880,40 …`(出生坐标就在副屏)
- `touchedPrimaryScreen=False`
- `onSecondary=True`

改过 `ui-reader/*` 之后**必须先 `cargo build`** —— 前端是编译期嵌进二进制的。

## 3. 待验的四项:具体怎么验

### 3.1 打字机模式
1. 打开任意长文档 → 进编辑 → 设置里把「打字机模式」打开。
2. 连续回车 30 次:光标行应始终停在视口约 38% 高度处,列表不抖。
3. 关掉开关再回车:恢复"到屏幕底部才滚"的原行为。

### 3.2 库级搜索排序 + 分组
1. 侧栏切「全文搜索」,搜一个既出现在**文件名**又出现在正文里的词。
2. 期望:文件名命中的文件排在最前;列表按文件分组,组头显示文件名 + 命中数;单个文件最多 8 条。

### 3.3 PDF 直出 + 媒体内联
1. 打开一篇带图片的文档 → 文件抽屉 → 「导出 PDF」。
2. 期望:文档同级出现 `<名>.export.html` 与 `<名>.pdf`;**PDF 没有页眉页脚**;PDF 会自动打开。
3. 打开 `.export.html`:图片应为内联(data:),把 html 单独拷到别的目录仍能显示图。
4. 负面:把机器上的 Edge/Chrome 临时改名 → 再点导出 PDF,应弹**可读错误**(不弹系统框)。

### 3.4 i18n 收尾
1. 设置里切 English → 随便触发几个操作(保存/删除/新建/导出),toast 不应出现整句中文。
2. 让后端报错一次(例如把文档所在目录设成只读再保存):错误应是英文前缀 + 细节。
3. 切回日本語 重复一遍。

## 4. 更新器:真装一遍(需要用户在场同意)

> 这一步会真的运行安装包。**必须**先跟用户确认时间窗,并且全程在副屏/隐藏方式下做。

1. 造一个"新版"安装包(不发布):
   ```powershell
   # 临时把 tauri.conf.json 的 version 抬到 1.8.0 后 npm run build 出安装包,再改回来
   powershell -File tools/make-release-manifest.ps1 -Dir src-tauri\target\release\bundle\nsis -Version 1.8.0 -Notes "本地演练"
   ```
2. 用一个**本地静态服务**托管该目录,并把清单地址指过去(测试缝):
   ```
   $env:TMMD_UPDATE_ENDPOINT='http://127.0.0.1:8799/latest.json'
   ```
   服务只需返回 `latest.json` 与 `*-setup.exe` 两个文件。
3. 起实例(第 1 节姿势)→ 设置→关于→「检查更新」→ 应提示发现 1.8.0 →「下载并安装」→ 进度跑到 100% → 应用退出 → 安装器静默装完 → 重开应是新版。
4. 观察点:`%TEMP%\tmmd-update.log` 有 `helper start` → `app exited, launching installer` → `launch returned`;`update_state.json` 记下了 `last_prompted`。
5. 负面:SHA-256 改错一位 → 必须**拒收并删除**下载物,错误里给出"期望/实际"。

## 5. 收尾(每轮必做)

```powershell
powershell -File <skill>\windows-hidden-desktop-verify\stopall.ps1
```

它会按命令行指纹杀净本任务起的进程(tmmd / tmmd-update-* / 假安装包)并清理临时脚本;
输出里 `tmmd running now: 0` 与 `cmd/powershell with my fingerprints left: 0` 是收工判据。

## 6. 已知的坑(踩过,别再踩)

1. **PS 脚本必须 ASCII**:Windows PowerShell 按 ANSI(本机 GBK)解码 `.ps1`,中文会串码并吃掉换行。
2. **一次一条命令、每条短(<40s)**:并发或长命令会触发"临时 shell"/后台作业,那会在用户桌面上**弹一个可见终端**。
3. **不要在自动化里起会弹 UI 的东西**(`cmd.exe`/安装器):失败会弹系统错误框 —— 假安装包那次就是这样吓到用户的;失败必须落日志文件。
4. **测试脚本必须有沙箱护栏**:只允许在 tmp 沙箱文件上输入/保存(此前把仓库 README 写成了一行,已修复)。
5. **改前端必须重建**:`ui-reader/*` 是编译期嵌入,不 `cargo build` 就跑的是旧 UI。
