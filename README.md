# TMMD

![TMMD hero — transparent local-first Markdown reader for Windows](assets/readme/hero.svg)

TMMD is a transparent local-first Markdown reader for Windows, built with Tauri 2 (Rust + WebView2). Fast, private, and entirely offline — your notes never leave your machine.

## Features

- **Multi-root library** — register several local folders as document roots; browse each via a sidebar file tree with directory outline
- **Local-first & private** — pure file-system access with a path-cage; no cloud, no telemetry, no accounts
- **Full Markdown rendering** — GitHub-flavored Markdown via [marked](https://github.com/markedjs/marked), math via [KaTeX](https://github.com/KaTeX/KaTeX), code highlighting via [highlight.js](https://github.com/highlightjs/highlight.js), **footnotes** (dependency-free pre-pass)
- **Reading comfort** — reading map (per-chapter metro view), outline with scroll sync, per-file resume position, **in-document find (Ctrl+F)**, **library-wide full-text search**, focus mode, immersive mode, adjustable line width / line height / body font
- **Transparent window** — frameless acrylic/Mica glass with three atmosphere presets, tint picker and a legibility floor; falls back to solid automatically when Windows transparency effects are off or high-contrast mode is on
- **Built-in editor** — edit any document inline and save back to disk
- **Export & print** — export a self-contained HTML next to the document, then print/save as PDF from the default browser
- **Tabs & history** — browser-style tabs with session restore, recents, per-file stars
- **Themes** — light/dark switching, three palettes (charcoal / paper / gruvbox), **UI in 中文 / English / 日本語**
- **Native installer** — NSIS + MSI bundles generated by Tauri

## Requirements

- Windows 10/11 (WebView2 runtime, installed by default on modern Windows)
- [Rust](https://rustup.rs/) (stable toolchain)
- [Node.js](https://nodejs.org/) 18+

## Build from source

```powershell
npm install
npm run dev       # development build with hot reload
npm run build     # release build → NSIS/MSI installers in src-tauri/target/release/bundle/
```

No separate frontend build step is needed: the frontend lives in `ui-reader/` and is embedded directly.

## Architecture

Frontend (`ui-reader/`) is a vanilla HTML/CSS/JS single page. The Rust backend (`src-tauri/`) exposes a small, capability-gated IPC surface:

| Command | Description |
|---|---|
| `desktop_info` | App version / platform info |
| `pick_folder` / `pick_file` | Pick a library root folder / a single document |
| `list_md_tree` | List `.md` files under a root (name + mtime sorted) |
| `read_text` / `write_text` | Read / write inside a registered root (path-cage enforced) |
| `open_path` / `save_path` | Open / save a single file outside the library (double-click mode) |
| `load_roots` / `save_roots` | Persist registered library roots (`roots.json` in app config dir) |
| `pending_open` | Cold-start CLI argument handoff |
| `set_glass_material` / `get_glass_state` | Window backdrop material (`none` / `acrylic` / `mica`) + tint |
| `system_effects_state` | Whether Windows transparency effects and high-contrast are on |
| `watch_file` | Watch the active document's folder; emits `fs-changed` |
| `search_library` | Full-text substring search across all registered roots |
| `export_file` / `open_any` | Write an exported `.html` / open any path with the default app |
| `open_default_apps_settings` / `get_md_default` | File-association helpers |

> Window geometry (size/position) is remembered in `window.json` in the app config dir; on launch the backend validates it against the current monitor work area and falls back to 88% of that work area when it no longer fits.

### Security model

- **Path cage**: every file read canonicalizes the root and rejects paths that escape it
- **Least privilege**: IPC permissions are declared in `src-tauri/capabilities/default.json`; the WebView has no network access permissions
- **No embedded shell**: external processes (browser/terminal) are spawned by the backend, not the WebView
